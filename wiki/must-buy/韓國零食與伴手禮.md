# 韓國零食與伴手禮

韓國零食在 [[Olive Young]]、便利商店（CU、GS25、7-Eleven）、大創、樂天超市都買得到。要買傳統伴手禮可以去 [[南大門市場]]。

## 推薦清單

| 品項 | 說明 | 哪裡買 |
|------|------|--------|
| Delight Project 貝果脆片、義大利麵造型餅乾 | 大蒜奶油貝果脆片曾是 2023 年韓國零食榜冠軍 | Olive Young |
| 農心牛角麵包餅乾 | 鹽味奶油、巧克力、覆盆莓口味 | 便利商店 |
| HBAF 杏仁 | 口味多，鹹甜都有 | 超市、便利商店 |
| 海苔 | YANGBAN、bibigo 等品牌，分即食、海苔酥、飯捲用 | 超市 |
| BICHOBI 餅乾 | 適合配咖啡 | 超市 |
| OSULLOC 茶 | 茶包與茶禮盒 | 專賣店、百貨 |
| Bricksand 磚形費南雪 | 15 種口味，每個約 ₩2,000–4,000 | 專賣店 |
| 魚板湯包、迷你藥果 | 便宜，適合大量分送 | 大創 |
| 草莓乾 | 平價伴手禮 | 南大門市場、廣藏市場 |

（來源：Funliday、蕃薯藤旅遊、MoneyHero）

## 選購小技巧

- 便利商店與超市的零食比 Olive Young 便宜，大量買可以去超市。
- 海苔、餅乾體積大，回程記得預留行李空間。
- 食品不能退稅（見 [[退稅]]）。
